# Billes

Jeu mobile de billes en 3D avec physique, développé avec Godot 4.4+.

## Lancer le prototype

1. Installer Godot 4.4 ou plus récent.
2. Ouvrir le dossier du projet dans Godot (fichier `project.godot`).
3. Appuyer sur F5.

## Contrôles (prototype)

- Glisser vers l'arrière depuis n'importe où sur l'écran puis relâcher : la bille part vers l'avant.
- Les joueurs tirent à tour de rôle. Au contact des deux billes, le tireur gagne la bille adverse.
- Tap pour passer à la manche suivante.

## Règles du prototype

- Une seule bille par joueur : le duel se joue pour une bille.
- Les bords du terrain sont des murs qui rebondissent.
- Le terrain est plat pour l'instant. Les surfaces (goudron, plaque à cases, cailloux) viendront ensuite.
